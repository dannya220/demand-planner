# Проверка переноса CatBoost на Kaggle

Результаты записаны из вывода Kaggle, присланного пользователем 21 октября 2026 года. [comparison.csv](comparison.csv) сохраняет показанную точность чисел; это не новые локальные расчёты.

Версия и ревизия CatBoost, параметры CPU-модели и число потоков совпали. Исходные `calendar.csv`, `sales_train_validation.csv` и `sell_prices.csv` совпали побайтно. NumPy, pandas и SciPy в окружениях отличаются.

В двух фрагментах по 30 490 строк совпали 62 из 63 признаков; отличался `price_relative_std_13w`. Локально Bottleneck отсутствовал, на Kaggle использовался pandas. После `pd.set_option("compute.use_bottleneck", False)` и очистки `price_features_at_origin.cache_clear()` все признаки обоих фрагментов совпали. Полный протокол — [reproducibility.json](reproducibility.json).

Это подтверждает источник найденного расхождения признаков. Влияние исправления на WRMSSE ещё не проверено: повторное обучение CatBoost отложено. Сохранённые здесь Kaggle-метрики относятся к запуску до исправления.

Дальше: первый LightGBM с отключённым Bottleneck, увеличение плотности обучения и ансамбль. Для окончательного сравнения моделей расчёт признаков должен быть согласован. Private-период для подбора не использовался.
