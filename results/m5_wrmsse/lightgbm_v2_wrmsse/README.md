
# LightGBM: выбор числа деревьев по WRMSSE

Обучение на Kaggle CPU, LightGBM 4.6.0. Использованы 63 признака и 52 еженедельные даты × 2 горизонта. Цель обучения — Tweedie 1.5; критерий ранней остановки — WRMSSE, ожидание 100 итераций, предел 3000 деревьев.

На окне 28 марта — 24 апреля 2016 года выбраны **386 деревьев**, WRMSSE **0.5549774227**, Bias **−2.20%**. Это окно участвовало в выборе числа деревьев.

Новая public-модель обучена до 24 апреля с фиксированными 386 деревьями. На 25 апреля — 22 мая получены WRMSSE **0.6787931078**, Bias **−5.98%**. Параметры и версии находятся в `config.json` каждого периода.

`historical_comparison.csv` сохраняет первый неудачный опыт с остановкой по Tweedie. `public_comparison.csv` сравнивает LightGBM с прежним Kaggle CatBoost до исправления Bottleneck. Это предварительное сравнение разных вариантов подготовки.

Модели и полные прогнозы исключены из Git. Они входят в локальный checkpoint; относительные пути сохранены при распаковке в корень проекта.
