# Demand Planner

Учебный проект: прогноз продаж и планирование закупок при ограниченном бюджете.

Сначала исследуем данные M5 и строим недельный прогноз. Затем добавим планирование закупок, проверку решений на истории и небольшое демо.

## Текущий статус

Завершены разделы **0–7** [исследовательского ноутбука](notebooks/01_exploration.ipynb): подготовка данных, EDA, три простых прогноза, CatBoost, диагностика ошибок и финальная проверка по времени. Текущий прототип использует **100 товаров FOODS магазина CA_1**, а не весь M5. Описание исходных данных: [docs/data.md](docs/data.md).

Выбор модели выполнялся на восьми неделях валидации. Затем CatBoost с MAE и 164 деревьями переобучен на данных до 27 марта 2016 года и проверен на четырёх следующих неделях. Для каждой недели прогнозируем её сумму после завершения предыдущей: факты уже завершившихся тестовых недель доступны для последующих прогнозов.

| Метод | MAE на валидации | MAE на тесте | WAPE на тесте | Bias на тесте |
| --- | ---: | ---: | ---: | ---: |
| Среднее за 4 недели | 4,84 | 4,28 | 30,58% | +1,97% |
| CatBoost с MAE | 4,62 | 4,21 | 30,05% | -2,61% |

Тест: **28 марта — 24 апреля 2016 года**, 400 прогнозов «товар–неделя». MAE измеряется в единицах на товар за неделю; WAPE — сумма абсолютных ошибок относительно фактического объёма; Bias — знаковое отклонение суммарного прогноза. Снижение MAE относительно заранее выбранного baseline — **1,75%**, с выигрышем в **2 из четырёх недель**. Это небольшой результат одного периода, который ещё предстоит проверить при расширении данных. EDA охватывает всю историю; тестовые ответы не использовались при выборе настроек, ранней остановке или финальном обучении.

Полные [таблицы результатов и прогнозов](results/weekly_pilot) создаются этапом 7. Сохранённая локальная модель находится в `models/catboost_weekly_pilot.cbm` и исключена из Git. Расчёты закупок, вероятностный прогноз и демо — следующие части проекта. Недельные метрики прототипа не являются Kaggle score.

Во [втором ноутбуке](notebooks/02_scaling.ipynb) начат запуск на всём CA_1: 3 049 товаров трёх категорий, 832 377 недельных строк. Продажи сразу складываются по неделям, без создания длинной дневной таблицы. Недельная таблица занимает около 23 МБ, с прежними признаками — 96 МБ.

Подготовлены данные, признаки и простые прогнозы. На восьми неделях валидации среднее четырёх недель даёт MAE 3,56 и WAPE 34,98%. Оценены 24 390 строк, где к дате прогноза уже была запись о цене. Это другой состав товаров, поэтому метрики сравниваются внутри второго эксперимента. Четыре последние недели помечены как `reference`, поскольку их уже смотрели на пилотной выборке.

Таблицы сохранены в [results/ca1_scaling](results/ca1_scaling). CatBoost на полном магазине — следующий шаг.

## Окружение

Python 3.12. Виртуальное окружение находится в `.venv` и не сохраняется в Git.

Для установки на другом компьютере из корня проекта:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m ipykernel install --sys-prefix --name demand-planner --display-name "Python (demand-planner)"
```

`requirements.lock.txt` фиксирует версии, проверенные при первоначальной настройке на macOS с Python 3.12. Для повторения этого окружения используйте его вместо `requirements.txt`.

## Ноутбук

Запуск из корня проекта:

```bash
source .venv/bin/activate
jupyter lab notebooks/01_exploration.ipynb
```

В ноутбуке выберите ядро **Python (demand-planner)**. В VS Code также можно выбрать интерпретатор `.venv/bin/python`.

## Структура

- `notebooks/01_exploration.ipynb` — завершённое исследование на 100 товарах.
- `notebooks/02_scaling.ipynb` — полный ассортимент CA_1, признаки и baselines.
- `data/raw/` — исходные данные, которые сохраняем без изменений.
- `data/processed/` — подготовленные таблицы.
- `src/data.py` — загрузка данных, дневная и недельная таблицы.
- `src/features.py` — недельные признаки, простые прогнозы и разбиение по времени.
- `src/train.py` — будущее обучение.
- `src/forecast.py` — будущий прогноз.
- `src/planner.py` — будущее планирование закупок.
- `src/backtest.py` — расчёт MAE, WAPE и Bias на одинаковых строках.
- `models/` — сохранённые модели.
- `results/` — небольшие таблицы результатов и графики.
- `tests/` — проверки недельной агрегации, доступности истории и метрик.
- `app.py` — будущее демо.

## Данные

Источник: [M5 Forecasting — Accuracy](https://www.kaggle.com/competitions/m5-forecasting-accuracy/data).

На первом этапе понадобятся `calendar.csv`, `sell_prices.csv` и `sales_train_validation.csv`. Их нужно разместить в `data/raw/`. Данные, окружение, сохранённые модели и секреты исключены из Git.

В M5 наблюдаются продажи. Остатки, закупочная стоимость и сроки поставки для будущей симуляции будут заданы отдельно; результаты этой части будут зависеть от допущений.
